# NutriPapa — idea inicial

## Contexto
Mi padre está a dieta y necesita llevar un control semanal de comidas para su nutricionista.
El objetivo es que ese control **no se le haga pesado**: rápido, visual y flexible.

## Qué es
Un dashboard (móvil y PC) para registrar las comidas de la semana.

## Estructura de la tabla semanal
- **Cabecera:** título, número de semana, número de menú y fecha.
- **Columnas:** lunes a domingo.
- **Filas de comidas:** desayuno, media mañana, comida, media tarde, cena.
- **Filas extra de seguimiento:** agua, WC, ejercicio.

## Requisitos clave
- Cada semana puede evolucionar (el menú cambia).
- Si repite una comida, no tiene que volver a escribirla: reutilizar comidas anteriores
  (sugerencias, favoritos, copiar día/semana, etc.).
- Añadir comida debe ser visual, entendible, fácil y flexible.
- Al final: compartir la semana como **PDF o imagen**, clara para la nutricionista.
